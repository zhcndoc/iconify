# 递增版本号

本教程是 [Iconify Tools](../index.md) 中 [包函数文档](./index.md) 的一部分。

函数 `[func]bumpVersion()` 是一个用于递增版本号的简单函数。

在更新现有包时，可用于自动递增版本号。

## 用法

该函数包含以下参数：

- `[prop]version`，`[type]string`。旧版本号

函数返回更新后的版本号。
