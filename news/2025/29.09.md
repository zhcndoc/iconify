## 适用于 Vue 的 SVG + CSS 组件 {#svg-css-vue}

全新易于使用的 Vue 图标组件已发布。

详情请参阅 [适用于 Vue 的 SVG + CSS](/docs/usage/svg-css/vue/index.md)。

目前有超过 200 个图标组件包，每个图标集对应一个：

- `[npm]@iconify-vue/material-symbols` 用于 Material Symbols 图标
- `[npm]@iconify-vue/solar` 用于 Solar 图标
- `[npm]@iconify-vue/tabler` 用于 Tabler 图标

……以此类推。

要导入图标组件，请从 `[npm]@iconify-vue/prefix/icon` 导入默认项，其中 "prefix" 为图标集前缀，"icon" 为图标名称。

示例：

```js
import GithubIcon from "@iconify-vue/ri/github-line";
```

然后在 Vue 模板中使用：

```xml
<GithubIcon height="1em" />
```

当 Iconify 图标集更新时，这些包将自动同步更新。
