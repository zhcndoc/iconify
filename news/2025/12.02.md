## Iconify API 更新 {#api-311}

Iconify API 3.1.1 版本已发布。

本次更新包含一项关键错误修复。如果您正在运行 API 实例，请尽快进行更新。

API 可通过以下途径获取：

- [GitHub](https://github.com/iconify/api/) - 您可以在部署前对其进行自定义。
- [NPM](https://www.npmjs.com/package/@iconify/api) - 无需运行完整服务器即可嵌入到应用中。
- [Docker](https://hub.docker.com/r/iconify/api) - 适用于快速部署。

请参阅 [API 文档](/docs/api/index.md)。
