## Iconify Tools 版本 4.0.0 {#tools-4}

Iconify Tools 版本 4.0.0 已发布。

这是一个破坏性更新，详见下文。

### 变更内容

有哪些变更？
- 从 Figma 导入图标时支持并行请求。这是一项重大改进，可将导入时间缩短 5 倍！
- 内置的 fetch 已被替换为 axios，速度更快，且支持配置代理服务器。
- 解决了处理大型图标时调用栈过大的问题。这需要引入破坏性更新，详见下文。

### 破坏性更新

部分函数原本是不必要的异步函数。

为了允许在同步环境（例如 Tailwind CSS 插件的配置文件）中使用 Iconify Tools，Iconify Tools 的某个先前版本引入了异步函数的同步变体。但这在处理超大图标（500kb+ 的图标……是的，它们确实存在……）时导致了调用栈过大的问题。

版本 4.0.0 将以下函数改为同步函数：
- `[func]validateColors()` - 检查 SVG 中的调色板（用于检查图标中的颜色）。
- `[func]parseColors()` - 解析 SVG 中的调色板（用于更改颜色）。
- `[func]parseSVGStyle()` - 查找 SVG 中的内联样式并进行解析，为每个条目调用回调函数。这是一个非常基础的解析器，无法处理高级 CSS。
- `[func]cleanupGlobalStyle()` - 查找图标中的 `[tag]<style>` 并将其应用到元素上。这是一个非常基础的解析器，无法处理高级 CSS。
- `[func]parseSVG()` - 解析 SVG，为每个元素调用回调函数。许多解析图标的内部函数都会使用它。
- `[func]deOptimisePaths()` - 移除旧版软件不支持的某些路径优化。

以下函数已被移除，因为不再需要它们：
- `[func]validateColorsSync()` - 请使用 `[func]validateColors()`。
- `[func]parseColorsSync()` - 请使用 `[func]parseColors()`。
- `[func]parseSVGStyleSync()` - 请使用 `[func]parseSVGStyle()`。
- `[func]parseSVGSync()` - 请使用 `[func]parseSVG()`。

### Cheerio 类型

旧版本依赖于 `[npm]@types/cheerio`。此版本使用 `[npm]cheerio` 内置的 TypeScript 文件。

这是一个破坏性更新，因为如果你的项目中使用了 `[npm]@types/cheerio`，在使用 Iconify Tools 时可能会遇到 TypeScript 错误。解决方案是不要使用 `[npm]@types/cheerio`，较新版本的 `[npm]cheerio` 已提供类型定义。

### 新增内容

新增属性：
- `[prop]axiosConfig` - 用于配置 axios 的属性。可从 `[file]@iconify/tools/lib/download/api` 导入，其值包含 axios 请求的选项，例如，要配置代理，请设置 `[prop]proxy` 属性。

类中的新增方法：
- `[type]SVG` 实例中的 `[prop]toPrettyString()` 方法。它会生成格式化后的字符串。
