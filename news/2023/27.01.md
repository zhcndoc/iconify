## 使用 Iconify 组件时不包含 width 和 height 的 SVG {#components-size}

Iconify 图标组件已更新。

新版本支持从生成的 `[tag]svg` 中移除 `[prop]width` 和 `[prop]height` 属性。如果你使用 CSS 来调整图标大小，有时需要这样做。

要移除 width 或 height，请将其设置为以下值之一：`[str]unset`、`[str]undefined` 或 `[str]none`。

### 示例

在 `[npm]@iconify/vue` 组件中的示例用法：

```vue
<Icon icon="mdi:home" height="unset" />
```

这将从渲染的 `[tag]svg` 元素中同时移除 `[prop]width` 和 `[prop]height`。

### 仅移除单个属性

如果你只想移除一个属性（例如 `[prop]width`），则需要为 `[prop]height` 设置一个值：

```vue
<Icon icon="mdi:home" width="unset" height="1em" />
```

这将仅移除 `[prop]width` 属性。

### Web 组件

此功能在 `[npm]iconify-icon` Web 组件中不可用，因为它无法按预期工作。
