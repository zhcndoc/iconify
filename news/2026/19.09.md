## API deployment script {#api-deployment}

Deploying Iconify API on your own server used to be hard for people not familiar with server management.

To make it easier, now Iconify API includes a deployment script that can be used to set up VPS and deploy API.

It is very easy to use and requires very few steps. All server stuff is automated.

What script does:

- Automatically sets up Node.js and PM2 on server.
- Uploads API files to server.
- Starts API server.

What you need to do:

- Setup a VPS (very easy - just few clicks, docs explain every step).
- Clone Iconify API repository, build it, run deployment script (easy for anyone familiar with Node.js).
- Point your subdomain to VPS IP in Cloudflare or a similar service (very easy).

Additionally, there is a script for updating files on server without reinstalling Node.js and PM2.

See [API deployment documentation](/docs/api/hosting-js/deployment.md).
