## AI powered icons search {#ai-search}

AI powered search is now used on Iconify website and in Iconify plugin for Figma:

- In main search.
- When filtering icons in an icon set.

Old version showed direct keyword matches, which meant if you searched for "settings" and icon was named "cog", you wouldn't find it.

New version shows related matches, making it easy to find icons by related words.

What is the actual "AI" part? I've used AI to generate related keywords for each icon, creating a large database of related words. So actual search is not using AI, which would be expensive, but it is using AI generated data.
