## 适用于 SolidJS 的 SVG + CSS 组件 {#svg-css-solid}

继推出 Vue、Svelte 和 React 组件之后，现已发布全新且易于使用的 SolidJS 图标组件。

详情请参阅 [适用于 SolidJS 的 SVG + CSS](/docs/usage/svg-css/solid/index.md)。

目前有超过 200 个图标组件包，每个图标集对应一个：

- `[npm]@iconify-solid/material-symbols` 用于 Material Symbols 图标
- `[npm]@iconify-solid/solar` 用于 Solar 图标
- `[npm]@iconify-solid/tabler` 用于 Tabler 图标

……以此类推。

要导入图标组件，请从 `[npm]@iconify-solid/prefix/icon` 导入默认导出项，其中 "prefix" 为图标集前缀，"icon" 为图标名称。

示例：

```jsx
import GithubIcon from "@iconify-solid/ri/github-line";

function GithubLink() {
  return (
    <a href="https://github.com/iconify">
      <GithubIcon height="1em" />
    </a>
  );
}
```

当 Iconify 图标集更新时，这些包将自动更新。
