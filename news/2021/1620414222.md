## 所有图标组件均支持 API {#components-rewrite}

所有图标组件均已重写。

从现在起，所有图标组件均可按需从 Iconify API 加载图标
并支持自定义 API 提供商，其功能与 SVG Framework 保持一致。

组件的新版本：

-   Iconify for React: 3.0.0 alpha 0（使用 `[npm]@iconify/react@alpha` 进行安装）
-   Iconify for Vue 3: 3.0.0 alpha 0（使用 `[npm]@iconify/vue@alpha` 进行安装）
-   Iconify for Vue 2: 1.0.0 alpha 0（使用 `[npm]@iconify/vue2` 进行安装）
-   Iconify for Svelte: 2.0.0 alpha 0（使用 `[npm]@iconify/svelte@alpha` 进行安装）

包含 API 的 Iconify for React 包（`[npm]@iconify/react-with-api`）已被弃用。

新图标组件的源代码已[在 GitHub 上提供](https://github.com/iconify/iconify)。

新组件的文档已重写，详见 [Iconify 图标组件文档](/docs/icon-components/index.md)。
