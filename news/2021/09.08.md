## 新版图标组件现已稳定 {#components-rewrite2}

新版图标组件的稳定版本已发布。

所有组件均支持按需从 Iconify API 加载图标，并兼容自定义 API 提供商，功能与 SVG Framework 保持一致。

组件新版本：

-   Iconify for React: 3.0.0（使用 `[npm]@iconify/react` 进行安装）
-   Iconify for Vue 3: 3.0.0（使用 `[npm]@iconify/vue` 进行安装）
-   Iconify for Vue 2: 1.0.0（使用 `[npm]@iconify/vue2` 进行安装）
-   Iconify for Svelte: 2.0.0（使用 `[npm]@iconify/svelte` 进行安装）

包含 API 包的 Iconify for React（`[npm]@iconify/react-with-api`）已被弃用。

新版图标组件的源代码已[在 GitHub 上提供](https://github.com/iconify/iconify)。

[Iconify 图标组件文档](/docs/icon-components/index.md)。
