## Iconify 版本 1.0.2 {#version-102}

Iconify 版本 1.0.2 已发布。

此版本修复了 `[prop]IconifyConfig` 对象，该对象可用于设置自定义 Iconify 配置：

```html
<script>
	// 先设置配置，然后再加载 Iconify
	IconifyConfig = {
		defaultAPI: 'http://localhost:3000/{prefix}.js?icons={icons}',
		localStorage: false,
		sessionStorage: false,
	};
</script>
<script src="https://code.iconify.design/1/1.0.2/iconify.basic.min.js"></script>
```
