## Iconify Icon 2.0.0-beta.1 {#icon-200b1}

Iconify Icon Web 组件 2.0.0 beta 1 版本已发布。

此版本在 SVG 性能方面带来了巨大提升：它使用 `[type]IntersectionObserver` 来检查
图标对当前访问者是否可见，仅在图标可见时才进行渲染。

作为一个不错的附带效果，带有淡入动画的图标会在其进入视口时开始播放动画。

新版本已应用于本网站以及全新的 [Iconify 图标集网站](https://icon-sets.iconify.design/)。

要安装 beta 版本，请使用 `[npm]@next` 标签：

```bash
npm install --save iconify-icon@next
```

### 新增 "observe" 属性 {#icon-200b1-observe}

您可以通过更改 `[prop]observe` 属性来改变观察器的行为。

默认情况下，该功能是启用的。如需禁用，请将 `[prop]observe` 设置为 `[str]false`。

```html
<iconify-icon icon="mdi:home" observe="false"></iconify-icon>
```

在 `[type]IconifyIconHTMLElementClass` 的实例中，您可以使用 `[prop]observe` 属性来设置/获取布尔值。
